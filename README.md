# Growfinix Task 3: Customer Demographic Analysis

## Project Overview
This project analyzes customer travel enquiries using Python. It explores popular travel destinations, customer age distributions, and income brackets.

## Technologies Used
- Python
- Pandas
- Matplotlib
- Visual Studio Code

## Tasks Performed
- Loaded customer enquiry data from a CSV file.
- Checked missing values and removed duplicate records.
- Grouped customers by age and income brackets.
- Identified the most popular travel destinations.
- Generated bar charts and a histogram.
- Exported cleaned data and summary reports.

## Output Files
- cleaned_enquiries.csv
- destination_summary.csv
- age_group_summary.csv
- income_summary.csv
- popular_destinations.png
- age_histogram.png
- income_brackets.png

## How to Run
1. Install Python.
2. Install the required libraries using `python -m pip install pandas matplotlib`.
3. Place `tour_enquiries.csv` in the project folder.
4. Run `python task3_analysis.py`.

## Note
This version uses a sample dataset for practice. The analysis should be rerun with the official internship dataset before final submission.
